XPC (Xalether Privacy Chain / Xalether Primal Cipher) — это твой основной шифр, финальная версия которого (XPC-3) представляет собой тройной каскад, где данные последовательно проходят через три независимых слоя шифрования.

🔐 Как работает XPC-3

Пользователь вводит пароль

📐 Формат зашифрованного файла (.xpc)

┌──────────┬──────────┬──────────┬───────────────────┬──────────┬──────────┐
│  SALT    │ AES_NONCE│CHA_NONCE │  ENCRYPTED DATA   │   HMAC   │ PAD_LEN  │
│ 64 байта │ 12 байт  │ 12 байт  │   N × 64 байта    │ 32 байта │  1 байт  │
└──────────┴──────────┴──────────┴───────────────────┴──────────┴──────────┘


🛡️ Почему три слоя

Слой Зачем нужен Что будет если сломают
XPC-3 (внутренний) Твой уникальный шифр, который никто не знает Без взлома AES/ChaCha атакующий не доберётся до этого слоя
AES-256-GCM (средний) Проверенный временем стандарт Если найдут уязвимость в ChaCha — данные всё ещё под AES
ChaCha20-Poly1305 (внешний) Защита от timing-атак Если найдут уязвимость в AES — данные всё ещё под ChaCha

Даже если математически сломают один из трёх слоёв, данные останутся защищены двумя другими. Это defence in depth.
