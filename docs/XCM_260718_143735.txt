XCM (Xalether Cipher Mode) — это наш собственный режим сцепления блоков, который объединяет два классических подхода: CBC (зависимость от предыдущего блока) и CTR (независимый keystream). Это не даёт атакующему находить закономерности в зашифрованных данных.

🔐 Как работает XCM

Исходные данные (разбиты на блоки по 64 байта)
        │
        ▼
┌─────────────────────────────────┐
│  Шаг 1: Создание счётчика       │
│  IV (32 байта) → 64-байтовый    │
│  счётчик (дополнен нулями)      │
│  prev_block = нули (64 байта)   │
└─────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────┐
│  Для каждого блока:             │
│  1. keystream = XBE(счётчик,    │
│     ключ)                       │
│  2. mixed = блок XOR            │
│     prev_block XOR keystream    │
│  3. encrypted = XBE(mixed,      │
│     ключ)                       │
│  4. prev_block = encrypted      │
│  5. счётчик += 1                │
└─────────────────────────────────┘
        │
        ▼
  Зашифрованные блоки


🎯 Почему это стойко

Свойство Как достигается
Одинаковые блоки → разный шифротекст Зависимость от prev_block + keystream
Лавинный эффект Ошибка в одном блоке портит все последующие
Нет паттернов Двойное XOR (prev_block + keystream) маскирует любые закономерности
Защита от подмены блоков Нельзя переставить блоки местами — нарушится цепочка
Уникальность для каждого файла Случайный IV даёт разный keystream даже для одинаковых файлов

🔄 Расшифровка

Зашифрованные блоки
        │
        ▼
┌─────────────────────────────────┐
│  Для каждого блока (в обратном  │
│  порядке):                      │
│  1. keystream = XBE(счётчик,    │
│     ключ)                       │
│  2. mixed = XBE⁻¹(encrypted,    │
│     ключ)                       │
│  3. original = mixed XOR        │
│     prev_block XOR keystream    │
│  4. prev_block = encrypted      │
│  5. счётчик += 1                │
└─────────────────────────────────┘
        │
        ▼
  Исходные блоки


📊 Сравнение с другими режимами

Режим Тип Распараллеливание Защита от подмены Уникальность
ECB Простой Да Нет Нет
CBC Сцепление Нет (расшифровка) Частично Да
CTR Счётчик Да Нет Да
GCM AEAD Да Да (через тег) Да
XCM (наш) Гибрид Нет Да (через HMAC + цепочку) Да

Главная фишка XCM в том, что он дважды пропускает каждый блок через XBE: сначала для создания keystream, потом для шифрования смешанного значения. Это делает анализ шифротекста практически невозможным — даже зная исходный текст одного блока, атакующий не может вычислить ключ или предсказать другие блоки.
