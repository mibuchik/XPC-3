XKDF (Xalether Key Derivation Function) — это наш собственный генератор ключей, который превращает пароль пользователя в криптографически стойкий ключ. Его главная фишка — memory-hard защита, которая делает перебор паролей на специализированном железе (GPU, ASIC) невероятно дорогим.

🧠 Как работает XKDF

Пароль + Соль (64 байта)

        ▼

│  state = SHA3-512(пароль + соль) │

        │
        ▼
┌─────────────────────────────────┐
│  Шаг 2: Memory-hard seeding     │
│  1 048 576 блоков по 64 байта  │

│  Каждый блок зависит от         │
│  предыдущего (нельзя            │
│  распараллелить)                │

        │
        ▼
┌─────────────────────────────────┐

│  3 прохода по всем блокам       │

🔐 Почему это стойко

Атака Как XKDF защищает
GPU-перебор 64 МиБ памяти на ядро → RTX 4090 (24 ГБ) вмещает только ~375 параллельных попыток вместо миллионов
ASIC-атака 64 МиБ SRAM на поток → ASIC становится радикально дороже в производстве
Time-memory tradeoff Data-dependent доступ к блокам заставляет хранить всю память, нельзя сжульничать и пересчитать на лету
Радужные таблицы Уникальная 64-байтовая соль для каждого файла → нет смысла строить таблицы

Главная фишка XKDF — использование SHA3-512 вместо SHA256. Под SHA256 уже существуют готовые ASIC-майнеры (биткоин), а под SHA3 — пока нет. Это даёт нам фору в несколько лет.
